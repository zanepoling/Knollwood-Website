# Knollwood Website

Static site for Historic Knollwood (150 Major Reynolds Pl, Knoxville, TN 37919), hosted on GitHub Pages.

- `index.html` — public website (homepage).
- `reserve/index.html` — **private, invitation-only** reservation page. It is `noindex` and is not linked from the public site; it is reached only by its direct link (`/reserve/`). Booking is gated by an access code + Terms of Use agreement, and submissions post to a Google Apps Script.

Served at: https://zanepoling.github.io/Knollwood-Website/ (reserve page at `/reserve/`).
